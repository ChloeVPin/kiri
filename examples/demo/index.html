Clipboard

Read and write through the host-owned controller. JS never touches the OS clipboard directly.

Path operations

Path math and OS directory discovery, capability-gated. No env vars or filesystem roots exposed.

File sandbox

Scoped read/write inside the host sandbox. A path outside the scope is rejected.

HTTP allowlist

kiri.http.get is double-gated: the capability AND a host allowlist. An unapproved host is denied.
